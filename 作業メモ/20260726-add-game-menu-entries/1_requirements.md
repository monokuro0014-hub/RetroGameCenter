# メニューへのゲーム項目追加（6 タイトル）

## 今回やること

チーム開発として、レトロゲームセンターのメニューに以下 6 タイトルの
**メニュー項目（カード）を追加**する。ゲーム本体の実装は各担当が別途行うため、
本作業では**メニュー上の枠（COMING SOON カード）とサムネイルの用意まで**を担当する。

追加するタイトル：

1. へびゲーム（SNAKE）
2. スペースインベーダー（SPACE INVADERS）
3. ブロック崩し（BREAKOUT）
4. ワギャンランド（WAGYAN LAND）
5. ピンボール（PINBALL）
6. マリオカート（MARIO KART）

## 前提・整理事項

- メニューは [src/scenes/menu_scene.py](../../src/scenes/menu_scene.py) の `GAMES` リストで管理。
  `(表示名, シーンキー or None)` のタプルで、`None` は「COMING SOON」表示になる。
- サムネイルは [src/scenes/menu_thumbnails.py](../../src/scenes/menu_thumbnails.py) の
  `_DRAWERS` に無いキーだと `_draw_coming_soon`（?マーク）が使われる。
- **既存の `SPACE INVADERS`（None）が既にある**ため、今回の「スペースインベーダー」と重複する。
  → 既存の 1 件に統合し、二重登録しない。
- 既存の `PAC-MAN`（None）は今回のリストに無いが、**残す**（別タイトルのため削除しない）。

## スコープ（今回の担当）

- `GAMES` リストへ 6 タイトルを追加（スペースインベーダーは既存を流用）
- 各タイトルに専用サムネイルを用意する（?プレースホルダのままにしない）
- グリッド表示・選択操作が破綻しないこと（件数増加後のレイアウト確認）

## やらないこと（スコープ外・他担当）

- 各ゲームのシーン本体（`*_scene.py`）の実装 … 各ゲーム担当が実施
- `main.py` へのシーン登録 … 各ゲーム実装時に担当が追記
- ゲームロジック・当たり判定・SE 等
- concept.md / architecture.md の変更（今回は不要。必要が生じたら報告して承認を得る）

## 実装メモ

- 準備中（シーンキー None）でも専用サムネイルを出せるよう、`GAMES` タプルを
  `(表示名, シーンキー, サムネイルキー)` の 3 要素に拡張した。
  → 各ゲーム担当が本体を実装したら、2 要素目を `None` から実シーンキーに差し替えるだけでよい。
- カード枚数が 6→11 に増え 3 行に収まらなくなったため、グリッドを
  **3 列→4 列**に変更し、カードサイズ・余白を圧縮して 3 行で 600px 内に収めた
  （`COLS/CARD_W/CARD_H/GAP_X/GAP_Y/GRID_TOP` を調整）。
